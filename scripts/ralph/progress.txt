## Codebase Patterns
- Memory-constrained benchmarks use `sudo systemd-run --scope -p MemoryMax=<limit> -p MemorySwapMax=0` (cgroup v2, no cgexec)
- Drop page cache before benchmarks: `sudo sync && sudo sh -c 'echo 3 > /proc/sys/vm/drop_caches'`
- Shell test scripts use `grep -qF --` to safely match strings starting with `--`
- Benchmark scripts live in `scripts/`, tests in `tests/`
- `benchmark_data_loading.py` supports CLI overrides: `--num-workers`, `--obs-lens`, `--batch-sizes`, `--iterations`, `--warmup`
