## Codebase Patterns
- Youmu's `read_multi_column_aligned_py` returns **flat FloatArray** for LIST<FLOAT32> columns (not ListArray). Access rows via `arr[row * dim : (row+1) * dim].to_pylist()`. Image (BYTE_ARRAY) columns return BinaryArray with direct index access.
- The test fixture uses column names `observation.state`, `action`, `observation.images.image` (not the defaults `state`, `actions`, `image`). Always pass explicit column names when testing with fixtures.
- `get_shuffled_multi_column_indices_dataset_level(file_paths, ref_col_idx)` returns shuffled `(file_idx, rg_idx, page_idx)` triples. Triples may repeat — de-duplicate with `set()`.
- `read_multi_column_aligned_py` does NOT take a cache parameter (unlike `read_multi_column_row_range_py`). It opens the file directly each call.
- Within a file, episodes are packed contiguously: `global_frame = file_global_base + file_row` where `file_global_base = ep.start_frame - ep_row_offset`.
- Use `LiberoYoumuDataset._load_chunk()` as a static method to reuse chunk-loading logic across dataset classes.
- Multi-worker page partitioning must use deterministic assignment (sorted unique pages) since `get_shuffled_multi_column_indices_dataset_level` returns different random orders per call.
- When wrapping an `IterableDataset` with a transform, use `TransformIterableDataset` (not `MappingDataset`). `build_dataloader` auto-handles IterableDataset (skips sampler).

- Implemented `LiberoYoumuPageAlignedDataset(IterableDataset)` in `submodules/youmu/python/youmu/libero_dataset.py`
- Key design: page-level shuffled iteration → LRU page cache for edge anchors → shuffle buffer for sample randomization → finalize (decode images) on yield

- Groups anchors by page for efficient processing during iteration
- Stores raw PNG bytes in shuffle buffer, decodes only on yield to minimize memory
