- YAML configs use `yaml.safe_load`/`yaml.dump` — always use `safe_load` (not `load`) for security
- Training configs follow the pattern: model/data/train top-level sections

- Training launch: `torchrun --nproc_per_node=1 tasks/omni/train_qwen_vl_libero.py --config <yaml>`
- For single-GPU benchmarks, set global_batch_size = micro_batch_size
- Config naming: youmu_page_aligned -> bench_page_aligned_bs{N}.yaml, lerobot -> bench_lerobot_bs{N}.yaml
- tqdm output (stderr) contains it/s or s/it rate; parse last occurrence for overall rate
- OOM detection: check exit code != 0 AND presence of "CUDA out of memory" or "OutOfMemoryError"
- GPU memory monitoring: poll nvidia-smi in background thread during subprocess training runs
